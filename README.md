# QR Code Generator

A simple QR Code Generator built using HTML, CSS, and JavaScript.

This project allows the user to enter text or a URL and generate a QR code by clicking the "Generate QR Code" button.

## Features

- Enter text or a URL
- Generate a QR code from the entered content
- Simple and easy-to-use interface
- QR code is generated dynamically

## Technologies Used

- HTML
- CSS
- JavaScript
- QR Code API

## How It Works

1. Enter any text or URL in the input field.
2. Click on the "Generate QR Code" button.
3. The entered content is sent to a QR code generation API.
4. The generated QR code is displayed on the page.
